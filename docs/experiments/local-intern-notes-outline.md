# 本地第二步资料生成优化

2026-10-28。基于 `8a819d4`，本地试用 `SKILLTREE_PREPARATION_GENERATION=notes-outline-v1`，提示版本为 `notes-outline-2`。未推送 GitHub 或部署云端。

## 改动范围

保留原 `StudyNotes(content: str)` 单字段 JSON、100～6000 字符业务契约及原有来源保存流程。资料仍标记为 AI 生成、未经独立来源核验，不改写历史资料或冻结记录。

根据已确认的 `scope_in` 提供完整 Markdown 二级标题，通常建议每分支约 300 字符，整篇目标约 2800 字符，复杂分支可以适度展开；标题较长时按原 6000 字符合同调整建议空间。建议长度不是裁剪器或新增硬上限。保留定义规则、短例子、误解和练习方向，减少引言、重复例子、档案复述及长篇总结。

生成后核对全部标题与原顺序，每节须有实质正文。Markdown 代码围栏内的示例标题不会被误计为章节。缺章、空章或结构错误进入原有一次修复流程，禁止截断后当作成功。目录校验证明覆盖形状与正文存在，不证明全部知识事实正确。

第一步的模型请求与原实现保持相同。第二步缓存输入增加提示版本，沿用原有持久化任务预算；未改画像、评分规则、节点解锁、配额或数据库结构。范围、资料、Planner 的日志分别记录完整阶段耗时与缓存复用，日志不含提示正文、答案或凭据。

## 实测

同一 Intern-S2，温度 0，关闭思考模式，单工作线程，交错新旧模式顺序。使用自编 SQL、数学范围，不写入生产数据。

早期 `notes-outline-1` 四组配对均首次结构通过，中位耗时 85.141→39.024 秒。但人工复核发现 SQL 例子漏写关键字、数学条件不完整，因此不能把这个降幅作为最终版结果。

补充必要条件、完整语法和实现差异自检提示并适度增加每章建议篇幅后，最终 `notes-outline-2`：

| 样本 | 原格式 | 新提纲 |
|---|---:|---:|
| SQL，7 分支 | 41.063 秒／3139 字符 | 36.203 秒／2358 字符 |
| 数学，6 分支 | 61.859 秒／4264 字符 | 52.719 秒／1361 字符 |

两种格式均首次通过 2/2，各两次请求、零输出修复。最终两组中位耗时 51.461→44.461 秒，约下降 13.6%。样本很少且模型耗时有波动，不能推广为所有目标的固定收益，更不能解释为完整工作流只需 44 秒。流式提供方没有返回 Token 用量，按未知记录。

人工检查仍发现部分知识表述不准确，例如数学资料的一处去括号说明；原格式也观察到知识错误。**本轮未通过全面课程事实审校，只完成结构、目录和业务流验收。当前定位为本地试用，未据此发布生产。**

## 实际业务状态验收

在新的独立本地数据库中，经与前端相同的 API 创建 SQL 课程：范围阶段 21.077 秒，资料阶段 44.842 秒，Planner 阶段 38.229 秒，阶段耗时合计 104.148 秒（不含全部外围处理）。三个阶段均一次请求成功，没有输出修复。

确认保存了 8 个节点、8 条边，包含一个分支点与一个汇合节点；Tutor 正常讲解并带真实资料引用。实际前端点击生成小测后，进入 `awaiting_answer`，显示一题单选和一题文字题。没有把 HTTP 200 单独作为验收依据。本轮没有重跑完整评分与补弱流程。

只读刷新没有追加模型调用。原有六个本地项目在三份 SQLite 数据库的三十一张表中与事前备份一致。

完整回归：1045 项通过，两个既有 websockets 弃用警告。完整回归后调整了篇幅建议、自检提示及长标题边界，最终受影响专项 79 项通过，结果保存在 `work/local-notes-outline-final-targeted.log`。测试记录脚本曾取错教学页字段，已从保存状态补齐报告，未重复模型请求。

## 复现和回退

真实配对（会调用现有模型 API 并消耗配额）：

```powershell
python scripts/benchmark_preparation_content.py --live --stage notes --case sql --case arithmetic --mode legacy --mode notes-outline-v1 --workers 1
```

可加 `--repeat 2` 做重复配对。脚本必须显式 `--live`，输出目录必须不存在。原来的 `content-v1` 是前一轮未启用的数组结构实验，与本模式不同。

本地 `.env` 已启用 `notes-outline-v1`，正常使用根目录 `python app.py`，访问 `http://127.0.0.1:8765/`。独立验收环境为 `http://127.0.0.1:18766/`，使用自编测试课程和独立数据库。

回退时将 `SKILLTREE_PREPARATION_GENERATION` 改为 `legacy` 并重启。保留数据库，不用旧备份覆盖新增学习记录；出题开关 `SKILLTREE_QUIZ_GENERATION` 独立保留。

本机证据目录：`work/local-notes-outline-final-paired-20261028`、`work/local-notes-outline-live-20261028`。日志为 `work/local-notes-outline-full-regression.log` 与 `work/local-notes-outline-final-targeted.log`。早期试验保存在 `work/local-notes-outline-paired-20261028`，没有删除失败或不合格内容记录。
