# Planner：学习目标与作答契约

新规划协议 `assessment-design-2` 将自然语言目标与测评说明分开。学习目标不需要包含某个动词，作品名称也不使用允许名单。

```json
{
  "learning_target": "讲清新文化运动中科学观念的含义",
  "source_chunk_ids": ["s1"],
  "assessment_tasks": [{
    "task_form": "text",
    "submission": "白话文演讲稿",
    "requirements": ["以新文化运动为背景", "围绕科学救国，约200字"],
    "criteria": ["历史背景准确", "核心概念正确", "解释清楚"]
  }]
}
```

`task_form` 仅有 `choice`、`numeric`、`text`，与已有选项、单数值、文字评分接口对应。程序绑定评价器、证据类型、目标身份，不允许模型另选权限、填写通过结果或降低标准。混合目标需要分别列出相应任务；同一形式每目标最多一项，全树必要目标仍需覆盖档案要求的评价能力。

`submission`、`requirements`、`criteria` 描述提交物、具体要求与评价依据；不得用空泛标签占位。模型通过 `source_chunk_ids` 选择真实资料，程序将已校验的原文绑定到教学和出题上下文，不再要求模型重复抄写已知原文。来源的项目归属、可见性、版本、身份和哈希仍严格校验。引用存在不等于语义支持已获证明：新目标的词汇重合度只产生运行警示，不能据其缺少某个同义词拒绝整课。旧版实验计划中的 `support_quote` 如存在，仍必须逐字符合选中的资料。

程序不判断开放目标是否命中“拟定／写出”“排列／排序”等词表。明确缺失任务内容、虚构摘录或已识别的真实安装／登录／执行完成认证要求，按内容问题进入原有一次修复；结构、身份、DAG、能力、评分与解锁约束仍硬校验。没有新增每目标的模型裁判或无限重试，总请求／网络重试／输出修复预算仍为 3/1/1。

课程、任务、量规之间的语义一致性仍需内容评测，模型生成具体任务并不等于自动批准其知识正确。现有出题与质量审查继续运行；出题收到当前题型对应的任务、要求和评价依据，由正式题目及冻结量规收集证据。文字回答不能证明真实口头演讲或外部操作已完成。

## 兼容已有课程

内部 `LearningObjective.observable_outcome` 保留原字段名，新规划将 `learning_target` 原文绑定到它；新增可选 `assessment_tasks` 记录独立测评设计。旧课程没有该字段时，序列化仍省略它，不批量迁移或重写已冻结计划、测评、Checkpoint 与预算。旧式无任务契约的数据沿用原兼容校验；所有新模型输出必须使用新作答契约。

来源摘录与任务信息只进入有权限的课程上下文。修复失败片段限长、标为不可信数据，不进入普通日志或公开终止诊断。终止诊断只保存受控错误类型、字段位置与内容错误分类。

准备阶段同时区分自述已会范围与新学习范围：已会部分可以背景衔接，不能一边排除详细复习，一边又把同一内容排成完整新章节；自述不会产生已通过记录。
