## 关键问题与具体证据

1. **9例最终诊断不可用。** 英语02/03/04/07、数学02/04/07、Python02/03。大多是remediate却把review_node_id填成当前节点。英语03首个最终对象额外复制内部上下文，第二次又错review_node_id。Python03此前两轮工具选择已消耗2次请求，最终错误后总额度3已满，所以无额外修复请求；它不能被描述成“实际已修复失败两次”。
2. **修复消息缺少原因。** v1原记录只给通用“解析失败”，未保留extra_forbidden或“只有先修回顾可指定复习节点”。已新加回归测试验证父异常链中的字段loc、类型及安全消息进入修复；测试不修改业务代码。
3. **数学03过度归因。** 查询前置历史为no_history；学生只说“只把左边的-2去掉，右边不变”，可支持非等价操作错误，不能进一步证明实际做过错误负数除法。合法前置ID和充分前置归因是两回事。
4. **严重性膨胀。** 数学02/07/08、英语08中，冻结critical=false的分项被评分器标critical，诊断还称其“关键标准”。这些例本来低分没有误通过，但不得把模型severity当冻结关键标准的事实；需明确二者职责并在后续报告记录。
5. **引用内容也有局部不足。** Python06的range规则不能单独证明自然语言“数到3”一定含3；有效的拒题理由应是端点未明、不能用单一答案键判错。数学08理由里的history ID被写成evidence:前缀，虽然数组里的合法ID正确，叙述仍不准确。
