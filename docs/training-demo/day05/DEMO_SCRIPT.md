# 单位学习演示脚本（约 6 分钟）

面向本地隔离实例或已准备好的验收环境。可用事先发布的短课减少现场等待；标注「已准备课程」时仍保留「新建」路径备查。

## 0. 开场（30 秒）

- 打开学习首页：说明「不是陪聊，是可验收的技能树」。
- 指出两条线：个人/游客自学 vs 单位任务学习。

## 1. 游客与注册（40 秒）

1. 未登录进首页 → 游客可自由学习。
2. （可选）注册个人账号，说明个人账号默认不属于单位。

## 2. 管理员：资料与短课（约 2 分钟）

账号：`admin@example.test`（本地示例密码见 `START.md`；公网用私有密码文件）。

1. **单位资料**：上传 `docs/training-demo/samples/` 中任意一份（建议 DOCX）。
2. 打开预览：指出正文、表格/来源位置；可选再点一次损坏扩展名文件看失败原因。
3. **已准备课程**（推荐演示）：打开已发布短课 → 下发给甲、乙（不选丙）。
4. **新建路径**（口播即可）：资料 → 生成计划 → 确认 → 发布 → 下发；现场若模型慢可跳过实操。

## 3. 员工甲：完整过关（约 2 分钟）

1. 甲登录 → 我的任务 → **开始学习**。
2. 进入学习台：讲解 → 测评 → 通过 → 叶子生长；连续完成必学节点。
3. 切回管理员看板：甲「已完成」、必学进度满格。

## 4. 员工乙：答错与补弱（约 1 分钟）

1. 乙开始同一任务（独立项目，进度不共享）。
2. 故意答错 → 指出诊断/补弱状态（未算完成）。
3. 看板：乙「进行中」、进度未满；逾期标记若有截止日则单独显示。

## 5. 丙与游客（30 秒）

1. 丙：任务列表为空；仍可自由学习。
2. 游客：个人资料学习入口可用；不出现在单位看板。

## 6. 收尾（20 秒）

- 强调：进度来自真实达标事实，不是客户端百分比。
- 说明当前为演示版边界（见 `LIMITATIONS.md`）；公网升级需备份与单独验收。
