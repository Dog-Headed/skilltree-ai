# 本地 Intern-S2 出题内容契约实验

基线为 `799c371b767466d05deed1adaff9d27bd040a117`。本实验仅在本地启用；范围整理、学习资料准备、Planner 路线生成、Tutor、评分和 Diagnosis 沿用现有业务契约。生产默认仍为 `legacy`。

## 开关与入口

在本机忽略提交的 `.env` 中设置以下开关，模型连接凭据沿用个人配置，禁止上传：

```dotenv
SKILLTREE_LOCAL_RUNTIME=production
SKILLTREE_QUIZ_GENERATION=content-v1
LLM_MODEL=intern-s2
SKILLTREE_THINKING_MODE=false
```

正常运行根目录 `python app.py`，访问 `http://127.0.0.1:8765/`。`production` 表示复用生产客户端及超时适配器，不会连接生产数据库或发布到公网。

## 实现边界

- 程序根据冻结目标、证据种类和最少题数分配题目槽位，保留必要目标，最多十题。
- 程序负责课程、节点、测评、题目、选项、目标、评价器、评分标准与来源的身份及版本，模型只返回受限的内容引用编号。
- 按单选、多选、数值、文字四种题型提供不同内容模板。文字题以固定 `r1/r2` 槽位填写评分内容，程序映射原冻结标准并计算总分。
- 数值题模型只返回 `expected/unit`。程序从内置单位表产生同维度单位白名单；无单位使用空名单，标量单位只接受其标准写法。容差使用冻结策略值。
- 不忽略多余字段，不补造题干或答案，不放宽最后的 `AssessmentQuiz`、来源、覆盖、精度及业务校验。
- 保留每个逻辑任务三次请求、一次网络重试、一次输出修复的共享上限。未实现第三项局部字段修复或服务端约束解码。
- 只影响之后生成的新题，已发布试卷、原答案和历史记录不会重写。

## 复现

离线回归：`python -m pytest -q`。Windows 浏览器测试需要在 `SKILLTREE_TEST_NODE` 指定 Node 可执行文件。

真实书生对照（会实际调用已配置的书生 API，不操作生产数据）：

```powershell
python scripts/benchmark_quiz_content.py --live
python scripts/benchmark_quiz_content.py --live --workers 1 --case money_mixed
```

脚本必须显式添加 `--live`；仅允许 Intern-S2、关闭思考模式，不自动切换模型。使用自编资料，交错新旧格式顺序，记录实际 Token、尝试次数、耗时和严格校验结果。输出目录必须不存在，避免覆盖旧证据。有限样本通过率与全流程体验需要分开评估。

## 已观测结果（2026-10-28）

最终九组配对样本均使用同一个书生客户端。新旧格式各生成十九道有效题，均首轮通过八组、预算内通过九组，各使用一次输出修复。出题中位耗时：旧格式 34.094 秒，新格式 7.453 秒；输入 Token 合计 31,181 与 11,222，输出 Token 合计 9,032 与 3,391。

这轮没有证明通过率高于旧版，也不是把完整学习流程从 120 秒降至 7 秒。新格式最慢样本 35.375 秒，包含一次 JSON 语法修复。此前实验曾出现多余字段和单位白名单冲突，保留失败记录后继续改进，未将失败记为成功。

本地真实页面/API 验收已覆盖正确作答解锁、错误作答零分后补弱重测满分再解锁，以及刷新草稿和只读查询不追加模型调用。详细运行证据保存在本机 `work/local-intern-content-final-20261028`、`work/local-content-remediation-live`，截图及报告在仓库上级 `deliverables`。

## 回退

将本地 `SKILLTREE_QUIZ_GENERATION` 改回 `legacy` 即恢复旧出题结构。需要恢复 DeepSeek 时，在本机用事前备份恢复 `.env`。停止本次本地服务后再切换版本；保留现有数据库，禁止用旧备份覆盖新学习记录。实验不会自动推送 GitHub 或部署到服务器。
