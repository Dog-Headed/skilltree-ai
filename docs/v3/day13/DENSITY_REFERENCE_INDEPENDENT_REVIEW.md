## 物理规则与来源

密度ρ=m/V表示单位体积的质量；80g÷20cm³=4g/cm³，即每立方厘米四克。定义与单位得到[OpenStax 11.2](https://openstax.org/books/college-physics-2e/pages/11-2-density)和[NIST密度词条](https://www.nist.gov/glossary-term/21726)支持。[NIST SI Guide第4章表2](https://www.nist.gov/pml/special-publication-811/nist-guide-si-chapter-4-two-classes-si-units-and-si-prefixes)将质量密度列为kg/m³，并与倒数体积量m³/kg区分。

在题目给出的理想均匀材料、同温同物态、无损耗且质量体积同比取样的条件下，取半为40g、10cm³，(m/2)/(V/2)=m/V，密度仍4。此为依据比值定义的数学推论，不冒称来自某原书题，也不推广到物态或结构变化、真实实验、气体任意过程等范围。V/m=0.25cm³/g是倒数方向，明确称它为本题密度属于所定义的概念错误。
