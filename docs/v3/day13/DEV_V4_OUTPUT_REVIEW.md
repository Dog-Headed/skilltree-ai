## 仍须如实保留的解释问题

1. **英语04分项编号被误解释。** 实际q1_c1考目标句型，q1_c2考动词形式，q1_c3考原意/时间；理由却分别称它们为过去肯定、过去否定、Did疑问。学生只写Yesterday，确实不满足三句型，1分且补弱成立；但不能把这些事实对应到错误分项标签。
2. **英语08混淆给分内容。** q1_c3的2分用于保留farm/yesterday和可理解原意。诊断却把“助动词作用说明错误”括注成“q1_c3得分但内容错误”，容易让学生以为该项被错误给分。应明确：意义时间项得分；否定结构和动词形式不得分，解释中的“不需助动词”另作错误证据。
3. **Python02文字过宽。** 作答已正确排除5，诊断先承认该证据，随后却统称“末端排除规则和最后一个值仍未掌握”。应缩小为完整序列及最后值仍错；这是反馈措辞精度问题，不改变5分或补弱结论。
4. **数学06一个附加理由不足。** k未知导致不能唯一数值8的核心依据充分；但“参考答案只给8，未展示全部步骤，所以不能按含步骤量规评价”不是必要成立：简写答案键可配合明确量规与可信资料评价步骤。不能把这个附加finding当成普遍作废规则；本例invalid_item仍由缺k的独立充分理由支持。

最小通用修复是让诊断读取实际冻结question_id/prompt/rubric.description，并按这些描述解释criterion_id；不必给它完整答案键，不改变推进权限、预算或批准分数中心。不能通过改标签掩盖上述实际输出。
