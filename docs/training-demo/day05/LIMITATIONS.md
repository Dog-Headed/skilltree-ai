# 单位学习演示：边界与已知限制

更新日期：2026-11-05（Asia/Shanghai）。2026-11-06 只更正下面「生产公网仍可能落后」这一条的适用日期；其余演示边界仍有效。当前同步见 [PROGRESS.md](../PROGRESS.md)。

## 产品边界

- 这是**单位学习演示闭环**，不是完整多租户 SaaS：单虚构单位、预置/脚本管理员、无计费与复杂组织架构。
- 正式测评依赖既有评价器与守卫；不能对任意学科名自动获得可靠评分能力。
- 不执行学员代码、不核验符号证明、不评测音频/发音/图像/实验操作。
- Office 上传有体积与页数限制；需打开密码、扫描件、旧版 Office、宏暂不支持。

## 演示与工程限制

- 真实模型规划/教学有等待与失败可能；演示可用「已准备课程」降低现场风险，不能因此关掉守卫或放宽通过线。
- 离线回归使用 Fake 模型走通状态机；教学忠实度与文案质量仍需真人抽检与（可选）真实模型短课复验。
- 补弱路径上，连续 `start_quiz` 可能进入可恢复的 `error`（需 `replace_assessment` / `return_to_teaching`）；演示以「答错 → 诊断/补弱态」为准，完整补弱再测建议按学习台提示操作。
- 进度看板只统计**本任务课程必学节点**；个人自学、游客项目不计入单位任务。
- 2026-11-05 曾写「生产公网实例可能仍落后于 GitHub `main`」。该句适用于当日（文档点名的公网提交是 `80d53f4`）。2026-11-06：GitHub 与服务器已同步到 `d948212`；healthz 版本标记 `SKILLTREE_COMMIT` 已在运维侧按部署提交写回。Windows 本机仓未强制覆盖、待用户自行同步。仍然禁止清空库，或用本地示例密码初始化公网。本地演示脚本不得覆盖生产目录。

## 安全与隐私

- 管理员不能因看板权限读取员工私人项目、对话原文或私有测评答案。
- 密码、模型密钥、公网账号表不进 Git；设备码/令牌仅存本机认证配置。
