## 保留的非关键表达与校准局限

- 数学02把表现称为“程序性缺失，而非概念误解”过于确定；一个短答案只能说明步骤未完成，不能证明学生内在误解类型已被唯一排除。当前补弱结论仍由直接错误及无同源历史支持。
- Python08称基础问题“一直未修复”也超出了两次观察的时间连续性；更准确是“当前与所查历史均出现”。两次同类证据足以支持先修回顾，但不证明期间每一时刻都薄弱。
- 英语07理由里有“先修补弱应围绕该点”这一不够准确的用词，但随后明确当前节点remediate、review_node_id为空，未实际回退前置。
- Python04和数学08各有2分边界差异，英语04有1分差异。允许误差通过不等于评分完全稳定，更不代表泛化到任意学科已被证明。

这些备注不涉及错误放行、错误业务事实或关键引用缺失，无需为修饰措辞而无限迭代开发集。应作为已知质量边界随最终报告保留，不能删除真实原输出。
