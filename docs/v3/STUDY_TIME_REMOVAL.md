# 学习时长分配下线（2026-11-04）

用户只填写目标和已有基础。范围、讲义和路线依据知识范围、基础、资料与评价能力生成；不要求填写总学习分钟数或每次学习分钟数，也不要求模型为节点估时。

Planner 生成和最终确认均取消总分钟数比较。模型内容协议不接收或输出 estimated_minutes；新课程不填造默认估时。创建页、范围预览、节点详情和学习小结不再展示计划时长。

旧课程的 time_budget_minutes、session_minutes 和 estimated_minutes 仍作为兼容元数据读取，并保持序列化往返；不重写旧课程、冻结快照或 Checkpoint。旧客户端发送合法的历史时间字段仍可接收，但不再限制课程生成。尚未使用的新课程不包含这些字段。

节点数、上下文、模型请求次数、评分标准、来源权限和解锁规则继续由原有约束控制。学习时长功能下线不增加 API 调用预算，不等于移除生成超时或访问限额。

生产删除入口同时修复：有账号会话的网关允许删除本人课程，要求同站请求、CSRF 和精确课程身份确认；排队或执行中的项目不可删除。删除不调用模型、不扣 AI 写操作额度，仍接受操作频率约束。旧无会话的评审代理继续禁止删除。
